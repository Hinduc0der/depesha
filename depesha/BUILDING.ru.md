# Как собрать Депешу самому

[English](BUILDING.md) · **Русский**

Готовых пакетов нет, и вот почему: в любой собранный `.sis` впечатаны **ключи
Telegram API**, а они у каждого свои (почему — ниже). Поэтому Депеша
собирается из исходников. Это дольше, чем скачать файл, но делается один раз и
по шагам ниже занимает вечер, из которого почти всё — ожидание установщика.

Нужен компьютер с **Windows**. Инструментарий 2011 года, другого под Symbian
не осталось.

---

## 1. Поставить Nokia Qt SDK

Нужен **Nokia Qt SDK 1.1** (в нём Qt 4.7.3 для Symbian и компилятор GCCE).
Nokia его давно не раздаёт; живые зеркала ищутся по названию файла
`Nokia_Qt_SDK_Win_offline_v1_1_2_en.exe` — например, на archive.org.

При установке:

- ставить **в путь без пробелов и без кириллицы**, по умолчанию `C:\QtSDK` —
  скрипты сборки рассчитывают именно на него;
- отметить **Symbian: Qt 4.7.3** и **Symbian^1 SDK** (в мастере это
  «Symbian» → «Qt 4.7.3 for Symbian Anna»);
- займёт около 3 ГБ.

Проверка: должен существовать файл
`C:\QtSDK\Symbian\SDKs\Symbian1Qt473\epoc32\tools\abld.pl`.

Если SDK встал в другое место, пути правятся в начале `build-symbian.bat`
(`SDKPREFIX`, `SYMBIANDIR`, `EPOCROOT`).

## 2. Получить свои ключи Telegram API

1. Откройте **my.telegram.org**, войдите по номеру телефона.
2. **API development tools** → заполните короткую форму (название приложения
   любое, платформа — Other).
3. Получите **App api_id** (число) и **App api_hash** (строка из 32 символов).

Теперь скопируйте `kutegram/quick/libkg/apisecrets.h.empty` в
`kutegram/quick/libkg/apisecrets.h` и впишите их:

```c
#define KUTEGRAM_API_ID 12345678
#define KUTEGRAM_API_HASH "0123456789abcdef0123456789abcdef"
```

Без этого файла сборка остановится с понятной ошибкой: `Please, specify an
API id.`

> **Почему нельзя взять чужие.** Ключ привязан к тому, кто его выпустил, и
> отвечает за всё, что с ним делают, тоже он. Telegram ограничивает и
> блокирует ключи, замеченные в массовом использовании из ниоткуда — вместе с
> аккаунтом владельца. Выпустить свой — две минуты, и это ровно та причина, по
> которой **готовый `.sis` никому передавать не стоит**: ключи внутри него.

## 3. Собрать

Положите рядом два каталога — так, как они лежат в репозитории:

```
...\kutegram\quick\      общий код: протокол и модели
...\depesha\             сама Депеша
```

и запустите:

```
depesha\build-symbian.bat
```

Скрипт сам скопирует исходники в `C:\dpbuild` (инструментарий 2011 года не
переваривает кириллицу в путях), соберёт и положит рядом с собой
`Depesha-<версия>.sis`. Первая сборка — минут десять, дальше быстрее.

Если что-то пошло не так, полный вывод компилятора остаётся в
`C:\dpbuild\build.log`.

Очистить рабочее дерево: `build-symbian.bat clean`.

## 4. Установить на телефон

`.sis` подписан **самоподписанным** сертификатом, поэтому телефон попросит
разрешения.

На телефоне один раз:

- **Средства → Дисп. прил. → Параметры → Настройки**
  (англ. `Tools → App. mgr. → Options → Settings`):
  - **Установка ПО: Все** (`Software installation: All`);
  - **Проверка сертиф. в сети: Выкл.** (`Online certif. check: Off`).

Дальше скопируйте `.sis` на телефон (кабель, Bluetooth, карта памяти) и
откройте его в файловом менеджере. Установщик спросит диск — подойдёт любой.

## 5. Медиа-сервер (по желанию)

Голосовые, кружки, видеостикеры и гифки этот телефон не декодирует и не
научится: ни Opus, ни VP9, ни Lottie. Их переводит в понятное телефону
(mp3, GIF, 3GP) **ваш собственный сервер** — любая машина с `ffmpeg`,
скрипт и разворачивание лежат в `kutegram/vps-media-convert.py` и
`kutegram/deploy-vps.sh`.

Адрес и токен вводятся на телефоне: левая софт-клавиша → **Settings** → Media
server. Чтобы не набирать их при каждой переустановке, скопируйте
`depesha/testdefaults.h.example` в `depesha/src/testdefaults.h` и впишите свои
— сборка подставит их сама.

**Без сервера всё остальное работает полностью**: текст, фотографии, обычные
стикеры, папки, ответы, отправка без звука и отложенная. У голосовых и видео
в списке будет стоять `no media server, press to save` — файл можно скачать и
забрать на компьютер.

## Если собираете часто

- **Поднимайте `VERSION` в `depesha.pro` перед каждой сборкой.** Скрипт
  выносит её в имя файла, пакеты ставятся вручную и копятся — иначе
  невозможно понять, что именно стоит на телефоне. Версия видна в заголовке
  приложения.
- `build-desktop.bat` собирает то же самое под Windows (mingw из того же SDK).
  Телефонного в нём нет, но ошибки компиляции видны за полминуты вместо
  десяти.
- **Не запускайте две сборки сразу**: обе работают в `C:\dpbuild` и затирают
  друг другу промежуточные файлы.
