# Депеша — клиент Telegram для Symbian S60v3

[English](README.md) · **Русский**

> Замысел, постановка задачи и проверка на живом железе — [@Hinduc0der](https://github.com/Hinduc0der).
> Код написан Claude (Anthropic) под его руководством.

Телефоны 2007 года: Nokia E90, N95, E71 и прочие на S60 третьего издания.
Делалось и проверялось на **E90**.

Внутри два каталога:

- **`depesha/`** — сама Депеша: интерфейс на обычных виджетах Qt 4.7,
  без QML. [README](depesha/README.ru.md) ·
  [Сборка](depesha/BUILDING.ru.md) · [Управление](depesha/CONTROLS.ru.md)
- **`kutegram/`** — [Kutegram](https://github.com/Kutegram/Kutegram), из
  которого взяты библиотека протокола (`libkg`) и модели данных, плюс
  серверная часть конвертера медиа.

## Собрать за один раз

1. Поставьте **Nokia Qt SDK 1.1** в `C:\QtSDK` (отдельно, его нельзя класть
   в архив — это инструментарий Nokia). Файл установщика называется
   `Nokia_Qt_SDK_Win_offline_v1_1_2_en.exe`.
2. Получите свои ключи Telegram API на **my.telegram.org** →
   *API development tools*.
3. Запустите **`СОБРАТЬ.bat`** — он спросит ключи, запишет их и соберёт
   `.sis`.

Подробно, со всеми тонкостями и настройками телефона — в
[depesha/BUILDING.ru.md](depesha/BUILDING.ru.md).

## Почему нет готового пакета

В любой собранный `.sis` впечатаны ключи Telegram API. Ключ привязан к тому,
кто его выпустил, и отвечает за всё, что с ним делают, тоже он: Telegram
ограничивает ключи, замеченные в массовом использовании из ниоткуда, вместе с
аккаунтом владельца. Свой выпускается за две минуты и остаётся только у вас.

## Как это делалось

Код написан **Claude** (Claude Code от Anthropic). Владелец репозитория ставил
задачи, проверял каждую сборку на живой Nokia E90 и находил то, что на
компьютере не видно: подвисания интерфейса, отвалы карты памяти, непонятные
пункты меню, неверную отправку. Почти все решения в этом проекте выросли из
такой проверки — журнал разработки состоит в основном из «сделал → проверил на
телефоне → оказалось не так».
